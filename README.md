### Hi, I'm Mohamed 👋

**Full-Stack Product Engineer** · Backend · Web · Mobile · DevOps

I build complete products — from database schema and APIs to web, mobile and production infrastructure. I work across the stack instead of handing the product from one layer to another.

- ⚙️ Backend systems, APIs and infrastructure that run in production
- 🌍 Arabic-first products built for Egypt and the Gulf
- 📱 Web + iOS + Android from the same product architecture
- 🔐 Security, CI/CD, testing and deployment are part of the build
- 🤖 AI is a tool in the workflow — not the product identity
- 🌙 ~60% of my commits happen between 6 PM and 2 AM
